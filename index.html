Power Automate Setup Guide

Connect your Microsoft Form directly to Firebase so every submission appears here automatically.

Your Firebase project is configured

Project: caliber-south-pto
Collection: pto_requests
Firestore rules set to allow read/write.

2

Create the Power Automate flow

Go to make.powerautomate.com
New flow → Trigger: "When a new response is submitted" → select your Caliber South PTO form
Add: Get response details

3

Add HTTP POST to Firebase

Add action: HTTP → Method: POST → URI:

https://firestore.googleapis.com/v1/projects/caliber-south-pto/databases/(default)/documents/pto_requests?key=AIzaSyAvKOxuIOvmRku_LzBGylyYfUAJwNhtW5c

Headers: Content-Type: application/json
Body:

{"fields":{"agentName":{"stringValue":"@{body('Get_response_details')?['r_fullname']}"},"agentEmail":{"stringValue":"@{body('Get_response_details')?['r_email']}"},"division":{"stringValue":"@{body('Get_response_details')?['r_division']}"},"startDate":{"stringValue":"@{body('Get_response_details')?['r_startdate']}"},"endDate":{"stringValue":"@{body('Get_response_details')?['r_enddate']}"},"dayCount":{"integerValue":"@{body('Get_response_details')?['r_days']}"},"reason":{"stringValue":"@{body('Get_response_details')?['r_reason']}"},"teamLeader":{"stringValue":"@{body('Get_response_details')?['r_tl']}"},"tlEmail":{"stringValue":"@{body('Get_response_details')?['r_tlemail']}"},"supervisor":{"stringValue":"@{body('Get_response_details')?['r_supervisor']}"},"supervisorEmail":{"stringValue":"@{body('Get_response_details')?['r_supemail']}"},"status":{"stringValue":"pending"},"submittedAt":{"stringValue":"@{utcNow()}"}}}
