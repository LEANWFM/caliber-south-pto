Power Automate Setup Guide

Follow these steps to connect your Microsoft Form → Firebase → email notification flow.

1

Create the Firebase Firestore collections

In Firebase console → Firestore Database → Start collection:
• Collection: pto_requests (leave empty — PA will create docs)
• Collection: alloc_config (leave empty — app writes this)
Then go to Firestore Rules and paste:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Admin app reads/writes all
    match /pto_requests/{doc} {
      allow read, write: if true;
    }
    match /alloc_config/{doc} {
      allow read, write: if true;
    }
  }
}
2

Get your Firebase Web API key for Power Automate

Power Automate will call Firebase REST API directly (no SDK needed).
Your REST endpoint is:
https://firestore.googleapis.com/v1/projects/YOUR_PROJECT_ID/databases/(default)/documents/pto_requests

In PA, use HTTP action with method POST and this URL. Add query param: key=YOUR_API_KEY

3

Create the Power Automate flow: Form → Firebase

Trigger: "When a new response is submitted" (Microsoft Forms)
→ select your Caliber South PTO form

Action 1: "Get response details" — get all form field values

Action 2: Calculate days until start date (add a Compose with expression):

// Days advance notice — paste in Compose expression
div(sub(ticks(outputs('Get_response_details')?['body/rXXX']),ticks(utcNow())),864000000000)

Action 3: Condition — check if days < 14 (short) or < 30 (long).
If violation → set autoStatus = "auto-denied", else autoStatus = "pending"

Action 4: HTTP POST to Firebase with body:

{
  "fields": {
    "agentName": {"stringValue": "@{body('Get_response_details')?['r_fullname']}"},
    "agentEmail": {"stringValue": "@{triggerOutputs()?['body/from']}"},
    "division": {"stringValue": "@{body('Get_response_details')?['r_division']}"},
    "startDate": {"stringValue": "@{body('Get_response_details')?['r_startdate']}"},
    "endDate": {"stringValue": "@{body('Get_response_details')?['r_enddate']}"},
    "reason": {"stringValue": "@{body('Get_response_details')?['r_reason']}"},
    "teamLeader": {"stringValue": "@{body('Get_response_details')?['r_tl']}"},
    "tlEmail": {"stringValue": "@{body('Get_response_details')?['r_tlemail']}"},
    "supervisor": {"stringValue": "@{body('Get_response_details')?['r_supervisor']}"},
    "supervisorEmail":{"stringValue": "@{body('Get_response_details')?['r_supemail']}"},
    "status": {"stringValue": "@{variables('autoStatus')}"},
    "submittedAt": {"stringValue": "@{utcNow()}"},
    "dayCount": {"integerValue": "@{variables('dayCount')}"},
    "ruleViolation":{"stringValue": "@{variables('ruleMsg')}"}
  }
}
4

Auto-denial email for rule violations

After Action 4, add a Condition: if autoStatus equals auto-denied:

Yes branch → Send an email (V2):
• To: @{body('Get_response_details')?['r_email']}
• CC: @{body('Get_response_details')?['r_tlemail']}
• Subject: PTO Request Auto-Denied — Caliber South
• Body: use the template below

Hi @{body('Get_response_details')?['r_fullname']},

Your PTO request for @{body('Get_response_details')?['r_startdate']} has been
automatically denied because it was submitted @{variables('daysAdvance')} day(s)
before the effective date.

Policy reminder:
• 1–5 day leaves: submit at least 14 days in advance
• 6+ day / annual leaves: submit at least 30 days in advance

Please resubmit following the correct timeline.

— Caliber South WFM
5

Approval / denial notification (triggered from this app)

Create a second flow with trigger: When an HTTP request is received (premium).
Or use free alternative: trigger on Firestore document update via the Firebase connector.

When status field changes to approved or denied:
→ Send email to agent + CC team leader + supervisor
→ Include the wfmComment field as the decision note

⚠️ The Firebase connector in Power Automate requires a premium PA license. Free alternative: this app writes approvals to Firestore, and a second PA flow polls Firestore every 5 min for status changes and sends emails.
6

Host on GitHub Pages

1. Create a GitHub repo: caliber-south-pto (private or public)
2. Upload this HTML file as index.html
3. Go to repo Settings → Pages → Branch: main → / (root)
4. Your app is live at: https://<your-username>.github.io/caliber-south-pto/

✅ Firebase credentials are stored in the browser (localStorage) so they're not visible in the HTML source on GitHub.
