Power Automate Setup — Free (no premium license needed)

✅ This guide uses only free PA actions — no Firebase connector or premium license required.
1
Form → Firebase (on each submission)
Trigger: When a new response is submitted (Microsoft Forms — free)
Action 1: Get response details
Action 2: Calculate days until start date (Compose with expression)
Action 3: Condition — check advance notice rule
Action 4: HTTP POST to Firestore REST API (free) with status = pending or auto-denied
Action 5 (if auto-denied): Send email to agent + CC team leader
2
Approval notification (free polling — no premium needed)
Trigger: Recurrence — every 5 minutes (free)
Action 1: HTTP GET from Firestore — query where status = approved OR denied AND notified = false
Action 2: Apply to each result → Send email to agent + CC team leader + supervisor
Action 3: HTTP PATCH to Firestore — set notified = true on that document
