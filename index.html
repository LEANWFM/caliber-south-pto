Follow these steps to connect Microsoft Forms to Firebase via Power Automate.

1

Firestore collections

In Firebase console, Firestore Database is already created. Collections will be auto-created when Power Automate posts the first document. No manual setup needed.

2

Power Automate — Form to Firebase

Create a flow: Trigger = "When a new response is submitted" on your Caliber South PTO form.
Action 1 = Get response details.
Action 2 = HTTP POST to:

https://firestore.googleapis.com/v1/projects/caliber-south-pto/databases/(default)/documents/pto_requests?key=AIzaSyAvKOxuIOvmRku_LzBGylyYfUAJwNhtW5c
3

HTTP POST body (JSON)

Use this as the body of your HTTP action:

{"fields":{"agentName":{"stringValue":"@{body('Get_response_details')?['r_fullname']}"},"agentEmail":{"stringValue":"@{body('Get_response_details')?['r_email']}"},"division":{"stringValue":"@{body('Get_response_details')?['r_division']}"},"startDate":{"stringValue":"@{body('Get_response_details')?['r_startdate']}"},"endDate":{"stringValue":"@{body('Get_response_details')?['r_enddate']}"},"reason":{"stringValue":"@{body('Get_response_details')?['r_reason']}"},"teamLeader":{"stringValue":"@{body('Get_response_details')?['r_tl']}"},"tlEmail":{"stringValue":"@{body('Get_response_details')?['r_tlemail']}"},"supervisor":{"stringValue":"@{body('Get_response_details')?['r_supervisor']}"},"supervisorEmail":{"stringValue":"@{body('Get_response_details')?['r_supemail']}"},"dayCount":{"integerValue":"@{body('Get_response_details')?['r_days']}"},"status":{"stringValue":"pending"},"submittedAt":{"stringValue":"@{utcNow()}"}}}
4

Approval notification flow

Create a second flow triggered when Firestore status changes to "approved" or "denied".
Send email to: agentEmail, CC: tlEmail + supervisorEmail.
Include the wfmComment field as the decision note.
